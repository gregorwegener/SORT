## Output folders

`outputs_expected/` contains the committed reference outputs for the release. These files define the expected reproduction state.

`outputs_generated/` contains outputs regenerated by a local reproduction run. The file `core3_summary.generated.json` is useful for comparing the current run against the reference summary without overwriting the expected outputs.

## Reproduction

```bash
cd evidence_releases/sort_ai_core3_kernel_damping_v1
python scripts/run_all.py
```

The script recomputes `kappa`, `xi`, scenario means, sample standard deviations, and coefficients of variation from the declared risk vectors. Generated outputs should be written to `outputs_generated/` and compared against `outputs_expected/` within declared rounding tolerances.
