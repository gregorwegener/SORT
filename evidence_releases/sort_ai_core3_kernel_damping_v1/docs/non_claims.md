# Non-Claims

This release makes the following exclusions explicit.

It does not claim:

1. That SORT has improved a production system.
2. That the values are telemetry from a deployed customer environment.
3. That this is a benchmark or performance comparison.
4. That any vendor, cloud, accelerator, runtime, orchestrator, or agent framework is evaluated.
5. That MOCK v4 is an execution engine.
6. That `sigma0` was independently fitted from AI telemetry.
7. That Core-3 covers all SORT-AI applications.

The intended claim is only that the declared Core-3 scenario values are reproducibly compatible with a Gaussian kernel-damping representation under `sigma0 = 0.00190643`.
