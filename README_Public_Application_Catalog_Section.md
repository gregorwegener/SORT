## Public Application Catalog

The SORT Framework defines structural risk assessment applications organized by **Domain** and **Cluster**.

### Licensing Architecture

> **Domains are the What. Clusters are the How. Applications are the Example.**

| Concept | Definition | Visibility |
|---------|------------|------------|
| **Domain** | Scientific upper space (AI, CX, QS, COSMO) | Public |
| **Cluster A–D** | Technical system levels | License-relevant |
| **Cluster E** | Evidence & Assurance layer | License-relevant |
| **Application** | Concrete manifestation | Public |

**Licensed is never the application, but the cluster.**

### Cluster Structure

| Cluster | Structural Focus | System Level |
|---------|------------------|--------------|
| **A** | Physical and logical coupling | Coupling |
| **B** | Temporal adaptation and learning | Learning |
| **C** | Operative control and coherence | Control |
| **D** | Emergent, non-linear behavior | Emergence |
| **E** | Traceability, auditability, justification | Evidence |

**Cluster E** is not a fifth technical level but a **cross-cutting license layer** addressing claims about systems rather than system behavior.
