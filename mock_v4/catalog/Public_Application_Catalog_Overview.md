## Purpose

This document provides a complete, executive-readable overview of all applications defined in the SORT Public Application Catalog.

Each application represents a distinct analytical or diagnostic perspective within the SORT framework. Applications serve as conceptual anchors for articles, white papers, and architectural analysis.

The authoritative source of record is the machine-readable `catalog.public.json`.  
This document is its human-readable counterpart.

## Cluster Structure

### Technical Clusters A–D (System Levels)

| Cluster | Structural Focus | System Level |
|---------|------------------|--------------|
| **A** | Physical and logical coupling | Coupling |
| **B** | Temporal adaptation and learning | Learning |
| **C** | Operative control and coherence | Control |
| **D** | Emergent, non-linear behavior | Emergence |

### Cross-Cutting Cluster E (Evidence Layer)

| Cluster | Structural Focus | System Level |
|---------|------------------|--------------|
| **E** | Traceability, auditability, justification | Evidence |

**Cluster E is not a fifth technical level but a cross-cutting license layer.**

Cluster E addresses not system behavior but **claims about systems**:

- Formal evidence provision
- Justifiability to third parties
- Auditability without implementation
- Evidence beyond internal engineering logic

**Strategic implication:**

> A customer can build systems **without E**.  
> But they cannot **defensibly represent them** without E.
